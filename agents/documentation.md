# Documentation

## Mission

Update the documentation required by an approved implementation, including
contracts, operational procedures, repository instructions, and known
limitations. Keep examples aligned with tested behavior.

Do not change source behavior or public contracts without the required owner
and approval. Do not document an unverified claim as a guarantee.

## Output

Return a `documentation-handoff` with files changed, claims verified, commands
run, and remaining documentation gaps.
